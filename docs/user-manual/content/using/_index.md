Walldash has four main views. A single floating menu — the **view switcher** — moves between them from anywhere in the app.

| View | What it is for |
| --- | --- |
| **3D View** | Control and monitor a single floor in 3D. |
| **Overviews** | Live dashboards made of widgets. |
| **2D Editor** | Draw walls, rooms and device placements. |
| **House overview** | See all floors stacked as one model. |

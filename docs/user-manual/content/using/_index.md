Walldash has a few main views. The top bar switches between **3D View** and **Dashboards**; the **plan editor** and dashboard editing live in **Setup mode**.

| View | What it is for |
| --- | --- |
| **3D View** | Control and monitor a single floor in 3D. |
| **Dashboards** | Live dashboards made of widgets. |
| **Plan editor (2D)** | Draw walls, rooms and device placements (Setup). |
| **House overview** | See all floors stacked as one model. |
